วิธีตั้งค่า (ทำครั้งเดียว)
  1. สร้าง Google Sheets ใหม่ แล้วเปิดเมนู ส่วนขยาย ➔ Apps Script
  2. ลบโค้ดเดิมทิ้ง แล้ววางโค้ดด้านล่าง กดบันทึก
  3. กด ทำให้ใช้งานได้ ➔ การทำให้ใช้งานได้รายการใหม่ ➔ ประเภท "เว็บแอป"
  4. ตั้ง "เรียกใช้ในฐานะ" เป็น ฉัน และ "ผู้มีสิทธิ์เข้าถึง" เป็น ทุกคน แล้วกดทำให้ใช้งานได้ (อนุญาตสิทธิ์ตามที่ขอ)
  5. คัดลอก URL ของเว็บแอป (ลงท้าย /exec) มาวางในช่องด้านบน พร้อมตั้งรหัสซิงก์
  6. ที่เครื่องอื่น วาง URL และรหัสเดียวกัน ข้อมูลจะมาเอง

รหัสซิงก์คือกุญแจของข้อมูลคุณ ใครรู้ทั้ง URL และรหัสก็อ่านและเขียนข้อมูลชุดนี้ได้ จึงควรตั้งให้เดายาก ฝั่งเซิร์ฟเวอร์เก็บรหัสในรูปแบบแฮช ไม่เก็บตัวจริง
